# LearnHub Backend

LearnHub is a backend API for a full-stack E-Learning Management System.

## Current Features  

- Course CRUD operations
- Lesson CRUD operations
- Course-Lesson relationship
- MongoDB database integration
- Mongoose models
- RESTful API structure
- Express.js routing
- TypeScript backend

- ## Tech Stack

- - Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- bcrypt
